Getting started

three things before the first run
  1. Tell Splitter where the game is. Open Settings and enter the game PC's address{% if desktop %} — it is pre-filled with this PC's address; if the game never connects, try another one from the list there{% endif %}.Game address set.
  2. Turn on the game's data feed. In VelociDrone: Options → Main Settings, set Websocket Communication and Websocket IMU Data to Yes, then restart the game.Game connected.
  3. Pick the track. Tap Track… above and choose the track you are flying. Single player never says which, and personal bests need it.Track set.
